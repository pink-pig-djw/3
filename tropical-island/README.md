# 小岛时光 · Tropical Island Diorama

一座放在胡桃木底座上的热带小岛微缩模型，用 Three.js 实时渲染，带移轴摄影效果。场景代码都在 `index.html` 里；`assets/` 里是用 Blender 制作的贴图和模型（见下文“Blender 资源”）。

## 打开方式

在这个目录下起一个静态服务器，再用浏览器打开（Chrome / Edge / Safari / Firefox 的较新版本），例如：

```sh
npx serve .            # 或者 python3 -m http.server 8000
```

页面会从 `cdn.jsdelivr.net` 加载 three.js（固定版本 0.186.1），从 Google Fonts 加载字体，所以第一次打开需要联网。
也可以直接双击打开 `index.html`，但浏览器不允许本地文件读取 `assets/`，这时会自动退回到纯程序生成的旧外观（岩石、椰子树、灌木、珊瑚和地面都没有 Blender 贴图），其他功能不受影响。

## 场景里有什么

- **更大的岛和海**：小岛约 1.4 倍尺度（面积约两倍），海域半径 76；从岸边到外海依次是浅泻湖（海草床、珊瑚丘）、北东侧的堡礁、礁前陡坡和深蓝外海
- 中央岩石山、从山崖落进水潭的瀑布，以及流向海边的小溪和木拱桥
- 八十多棵会随风摆动的椰子树（Blender 建模：每片羽状小叶一张贴图卡片，树干有树皮贴图和膨大的根基，地上有斑驳树影）
- 四种灌木（亮叶、浅绿大叶、变叶木、开花的扶桑）、红色朱蕉、开花的鸡蛋花树、成丛的草和蕨类；同种植物会成片生长，颜色艳丽的品种集中在小屋周围的院子里
- 栈桥连着的三座水上高脚屋、东边的码头和“椰子小铺”、四座椰林小屋、小岛上的灯塔
- 系在码头的小划船、绕岛航行的两艘帆船、出海兜圈的渔船（都有尾浪）
- 二十多个小人：沙滩散步、扛冲浪板、追浪花的小孩、栈桥上提灯的人、篝火边坐着的人、码头钓鱼、游泳、划桨板
- 海鸥、夜里的萤火虫、篝火火星，天上随风飘移的积云，以及云影掠过海岛

### 海洋生物

- 泻湖鱼群：蓝倒吊、黄高鳍刺尾鱼、镰鱼、鹦嘴鱼，珊瑚丘上方成对悬停的小丑鱼
- 礁前的银色饵鱼球（成百条小鱼绕圈游动）
- 沿外礁巡游的黑鳍礁鲨、贴着礁坡滑翔的蝠鲼
- 在泻湖里游动、定时浮上水面换气的绿海龟
- 外海的海豚群：贴着水面结伴前进，轮流跃出海面，出水和入水都有水花
- 座头鲸：在深处巡游，上浮后喷两次水柱，再抬起尾鳍下潜
- 深水区缓缓漂浮的水母，夜里会发出微光
- 沙滩上横着走的小螃蟹、浅水里的海星

## 海底探索

漫游模式里可以潜到海底到处看看，左上角的书本按钮、漫游栏里的“图鉴”或 `J` 键可以打开 **海洋图鉴**（手柄按下右摇杆）。

- **水下地点**
  - 沉船「晨星号」：礁坡下约 6 米深的木帆船残骸，船身长满珊瑚和海扇；周围有梭鱼群和石斑鱼，船尾旁有一只宝箱
  - 海底拱门：长满珊瑚的天然石拱，可以从下面游过去
  - 砗磲礁坪、东北堡礁、深蓝外海
- **新的海洋生物**
  - 章鱼：伏在礁石上伪装，靠近会变色、喷墨逃到别处
  - 海鳗：从石缝里探出头，嘴一张一合；靠太近会缩回去
  - 魟鱼：贴着沙底滑行，偶尔停下休息，受惊会加速游走
  - 砗磲：靠近时会合上壳，过一会儿再慢慢张开
  - 海马、海胆，还有长在小丑鱼身下随水流摆动的海葵
  - 鱼群会给游近的你让路
- **收集**：海底散落着 14 枚贝壳（凤尾螺、宝贝、扇贝、蝾螺），某只砗磲里藏着一颗珍珠，沉船旁有宝箱，泻湖沙底躺着一个漂流瓶（里面有一封信）。图鉴共 27 项（22 种生物、5 个地点），进度保存在浏览器里
- **憋气**：每口气大约能潜 50 秒，屏幕下方的条会提示剩余的气；没气了会自动上浮，出水后几秒就能缓过来
- **潜水装备**：码头上有一个潜水装备架，可以租面镜、气瓶和脚蹼。戴上之后能一直待在水下、游得更快，会吐出一串串气泡，视野边缘是面镜的框；再去装备架就能归还
- **水下的样子**：阳光会从水面透下一道道光束；水深超过约 1.3 米时可以悬停，不用一直按着下潜键；颜色按实际水的吸收变化，越远越偏蓝绿

## 真实感处理

- **光照**：用当前天空实时生成环境贴图（IBL），所有材质都会反射天空、得到来自天空和地面反弹的环境光；随时间和天气自动更新
- **海水**：
  - 按深度吸收红光：浅水在白沙上呈清透的绿松石色，越深越转向蓝绿，水下的沙、珊瑚、鱼和人都会被染色
  - 水面按物理菲涅尔反射天空；远处水面粗糙度自然变大，不会像亮片一样闪烁
  - 外海有长周期涌浪，风大（下雨）时出现白浪；泡沫是一簇簇气泡状的花边，夜里浪花里的发光浮游生物会亮起蓝光
- **沙滩**：Blender 烘焙的珊瑚沙贴图（沙粒、贝壳碎片、小卵石），加上风成沙纹、水下波痕；海浪一阵阵冲上沙滩又退回，留下湿亮的水膜和泡沫线；高潮线上有干海藻残迹
- **地形**：草地是一张在 Blender 里用真实几何体（草丛、落叶、椰叶碎片、石子、枯枝）俯拍渲染的贴图；陡坡自动换成岩石；每种贴图取两种尺度和角度混合，看不出重复。烘焙了环境光遮蔽，岩石脚下、沟谷和山体背面会自然变暗
- **岩石**：Blender 雕刻的岩石模型（凸包 → 体素重建 → 多层位移 → 减面，烘焙了环境光遮蔽），以及风化火山岩贴图（不规则色块、侵蚀凹坑、少量长裂缝、地衣斑），按三个轴向投影贴到山体和礁石上；靠近海水的部分更深、更有光泽
- **植被**：椰子树、灌木、朱蕉、鸡蛋花、草丛、蕨类都是 Blender 模型，叶片用同一张叶片贴图集（带透明裁切和法线），阴影也按叶片形状裁切；叶片逆光时会透出光来
- **珊瑚**：Blender 建模的鹿角珊瑚、桌形珊瑚、海扇、指状珊瑚、脑珊瑚和滨珊瑚丘，带珊瑚虫纹理和脑纹贴图；枝状珊瑚长在向阳的礁顶，块状珊瑚在礁丘之间
- **建筑、船、人物**：木板和茅草换成 Blender 烘焙的 PBR 贴图（木纹、年轮、裂纹、风化；茅草分层叠压），油漆褪色，表面有污渍和被晒白的斑块，粗糙度不均匀
- **天空和阴影**：天上是一层随风飘移的积云，按太阳方向打光，朝太阳一侧有亮边，黄昏被染成橙粉色，夜里遮住星星，下雨时变成阴云；同一张噪声图把云影投在海岛和海面上。第一人称时太阳阴影只覆盖玩家周围、跟着玩家移动，清晰度是全景时的两倍

## 第一人称漫游

按 `4` 或点相机栏里的“漫游”，就能以第一人称走上小岛（站在东南边的沙滩上开始）。

- **走路**：地形有坡度限制，太陡的岩壁爬不上去；能走上栈桥、码头、甲板和台阶，脚步声随沙地、木板、草地、浅水变化
- **下海**：走进深水会自动转成游泳，`空格` 上浮、`C` 下潜。水下有雾和悬浮颗粒，画面带一点折射晃动，抬头能看到水面的“斯涅尔窗”，声音会变闷
- **回到岸上**：游到栈桥、码头或高脚屋边会出现“爬上去”的提示；高脚屋外侧有梯子
- **划船**：码头边的小划船可以借走，`W` `S` 划桨、`A` `D` 转向，会留下尾浪；靠近帆船或渔船按 `E` 可以登船，随船绕岛航行，再按 `E` 跳回海里
- **进屋**：三座水上高脚屋和四座椰林小屋都能开门进去，里面有床、桌椅、台灯、书架和地毯；关着的门会挡路；窗户白天透亮、夜里变暗
- **互动**：准星附近能互动的东西会出现 `E` 提示，比如：
  - 和岛民打招呼（他们会转身挥手，说一句话）
  - 在椰子小铺买冰椰子
  - 坐吧台、坐门廊，躺在躺椅上晒太阳
  - 在篝火边坐下
  - 上床睡一觉（夜里会睡到天亮）
- **动作**：每种互动都有对应的第一人称动作，能看到自己的手臂：
  - 开门：伸手握住门把再推开或拉上
  - 坐下 / 躺下：转身、身体放低、落座时轻轻一顿；躺椅会再向后仰
  - 吧台：伸手接过椰子（或果汁、烤玉米），举到嘴边仰头喝，再放下
  - 打招呼：抬手挥几下，岛民也会转身挥手
  - 爬梯子：双手交替抓横档往上爬，再跨上平台；从平台也能顺梯子下水
  - 从水里爬上栈桥：双手撑住边沿，撑起、跪上去再站起来
  - 上船：跨进小船（从水里是攀着船舷翻进去），船会被压得晃一晃
  - 划船：双手握桨来回划，桨叶入水时溅起水花
  - 登帆船 / 渔船：攀上船舷；跳水：张开双臂跃出，低头看着海面落水
  - 游泳：蛙泳划水，手臂向外划开、收回胸前、再向前伸
  - 篝火：坐下后双手伸向火堆取暖
  - 睡觉：躺下看着天花板，眼皮慢慢合上，醒来时眨几下眼再起床
- **视野**：漫游时外海延伸到地平线，底座隐藏；关掉移轴模糊，泛光和灯光强度按近距离重新调过
- **小地图**：右下角是小地图，显示你的位置、朝向和船只
- **手机**：左下角是摇杆，滑动屏幕右半边环顾，右下角有互动、上浮、下潜、跑步按钮

| 漫游操作 | 作用 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动（划船时为划桨、转向） |
| 鼠标 | 环顾（点击画面锁定鼠标，`Esc` 释放；如果浏览器不允许锁定，就按住左键拖动） |

## 实现要点

- **光照**：一天按关键帧插值太阳/月亮颜色和强度、天空渐变、曝光与色调；夜里窗户、串灯、火把和灯塔亮起，水面会反射暖光。
- **水**：一张半精度高度图同时给海面算水深（浅水绿松石到深海蓝、岸边浪花、礁石白浪）、给雨滴算落点；水下物体统一做吸收染色，浅滩能看到焦散光纹。
- **后期**：HDR 渲染 → 泛光 → 移轴（焦点带跟随画面主体，亮点会散成柔和光斑）→ ACES 色调映射、白平衡、分离色调、暗角和颗粒。
- **声音**：全部用 Web Audio 实时合成，没有音频文件：海浪、风和树叶、鸟叫和海鸥、夜里的虫鸣、篝火噼啪、雨声、远雷，以及偶尔的风铃。
- **性能**：静态建筑合并成少量网格，植被用实例化；画质分“流畅 / 均衡 / 精美”三档，如果帧率持续偏低会自动降一档。手机上贴图会缩到一半大小，节省显存。

## Blender 资源

`assets/` 里的文件都由 `blender/` 下的脚本生成，不需要手工编辑。脚本用 Blender 4.5 的 Python 模块 `bpy`（`pip install bpy==4.5.*`，需要 Python 3.11 和 numpy、Pillow），也可以用 Blender 本体运行（`blender -b -P 脚本.py -- 参数`）。

| 脚本 | 生成 | 做法 |
| --- | --- | --- |
| `textures.py` | `assets/tex/{sand,rock,bark,thatch,wood,coral,brain}_{c,n,r}.webp` | 程序化材质节点（4D 噪声映射到环面上，保证无缝）烘焙成贴图；法线由高度图按真实尺寸计算 |
| `ground.py` | `assets/tex/ground_*.webp` | 用真实几何体（约 1.5 万个草丛、草叶、落叶、石子、枯枝）摆出一块 2 米的地面，正交俯拍渲染出颜色、法线、AO 和高度 |
| `foliage.py` | `assets/tex/foliage_{c,n}.webp`、`foliage.json` | 叶片贴图集：椰子小叶、各种灌木叶、草丛、蕨叶、扶桑和鸡蛋花，带透明通道 |
| `rocks.py` | `assets/models/rocks.glb` | 8 种岩石：凸包 → 体素重建 → 多层位移（起伏、崩口、颗粒）→ 减面，烘焙顶点 AO |
| `palms.py` | `assets/models/palms.glb` | 4 种椰子树，和页面里的布局一一对应 |
| `plants.py` | `assets/models/plants.glb` | 灌木、朱蕉、鸡蛋花、草丛、蕨类 |
| `corals.py` | `assets/models/corals.glb` | 6 种珊瑚 |
| `stats.py` | `assets/tex/stats.json` | 每张颜色贴图的平均色，页面用“贴图 ÷ 平均色 × 场景原有颜色”的方式叠加细节 |
| `preview.py` | 预览图 | 用 Cycles 把模型排成一排渲染出来检查 |

例如在 `blender/` 目录下：

```sh
python textures.py ../assets/tex          # 也可以只烘焙其中几张：python textures.py ../assets/tex rock bark
python ground.py ../assets/tex
python foliage.py ../assets/tex
python rocks.py ../assets/models
python palms.py ../assets/models           # 依赖 foliage.json
python plants.py ../assets/models
python corals.py ../assets/models
python stats.py ../assets/tex
```

`*_c` 是 sRGB 颜色，`*_n` 是 OpenGL 约定（+Y 向上）的切线空间法线，`*_r` 的 R/G/B 分别是 AO、粗糙度和高度。模型是 glTF 二进制（Y 轴向上），顶点色里是“底色 × 烘焙 AO”，自定义属性 `_SWAY` / `_FLUTTER` 控制风吹时各点摆动和叶片抖动的幅度。
