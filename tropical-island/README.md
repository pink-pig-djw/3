# 小岛时光 · Tropical Island Diorama

一座放在胡桃木底座上的热带小岛微缩模型，用 Three.js 实时渲染，带移轴摄影效果。整个场景只有一个文件：`index.html`。

## 打开方式

用浏览器直接打开 `index.html` 即可（Chrome / Edge / Safari / Firefox 的较新版本）。
页面会从 `cdn.jsdelivr.net` 加载 three.js（固定版本 0.186.1），从 Google Fonts 加载字体，所以第一次打开需要联网。
如果浏览器对本地文件有限制，也可以在这个目录下起一个静态服务器，例如 `npx serve .`。

## 场景里有什么

- 中央岩石山、从山崖落进水潭的瀑布，以及流向海边的小溪和木拱桥
- 几十棵会随风摆动的椰子树、灌木、花、草丛、蕨类，浅水里的珊瑚和海星
- 栈桥连着的三座水上高脚屋、东边的码头和“椰子小铺”、两座椰林小屋、小岛上的灯塔
- 系在码头的小划船、绕岛航行的两艘帆船、出海兜圈的渔船（都有尾浪）
- 二十多个小人：沙滩散步、扛冲浪板、追浪花的小孩、栈桥上提灯的人、篝火边坐着的人、码头钓鱼、游泳、划桨板
- 海鸥、夜里的萤火虫、篝火火星、会飘的云

## 交互

| 操作 | 作用 |
| --- | --- |
| 拖动 / 滚轮 / 右键拖动 | 旋转、缩放、平移（环绕模式） |
| 时间按钮或滑条 | 清晨、中午、黄金时刻、日落、夜晚，或任意时刻 |
| `空格` | 暂停 / 继续时间流逝 |
| `R` | 开关下雨 |
| `1` `2` `3` | 环绕 / 跟随 / 自动巡游 |
| `N` | 跟随模式下换一个对象（人物、帆船、渔船） |
| `M` | 开关环境音 |
| `H` | 隐藏界面 |
| `F` | 全屏 |

设置面板里可以调移轴模糊、泛光强度、时间速度、音量、画质，以及环绕模式下是否自动缓慢旋转。

## 实现要点

- **光照**：一天按关键帧插值太阳/月亮颜色和强度、天空渐变、曝光与色调；夜里窗户、串灯、火把和灯塔亮起，水面会反射暖光。
- **水**：一张半精度高度图同时给海面算水深（浅水绿松石到深海蓝、岸边浪花、礁石白浪）、给雨滴算落点；水下物体统一做吸收染色，浅滩能看到焦散光纹。
- **后期**：HDR 渲染 → 泛光 → 移轴（焦点带跟随画面主体，亮点会散成柔和光斑）→ ACES 色调映射、白平衡、分离色调、暗角和颗粒。
- **声音**：全部用 Web Audio 实时合成，没有音频文件：海浪、风和树叶、鸟叫和海鸥、夜里的虫鸣、篝火噼啪、雨声、远雷，以及偶尔的风铃。
- **性能**：静态建筑合并成少量网格，植被用实例化；画质分“流畅 / 均衡 / 精美”三档，如果帧率持续偏低会自动降一档。
